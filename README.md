# SDS Snackz Storefront

A faithful React + Vite rebuild of the SDS Snackz storefront homepage. The app includes responsive browsing, local product imagery, category navigation, search, cart interactions, contact form state, and a live chat affordance.

## Run locally

pnpm install
pnpm --filter @workspace/sds-snackz-storefront run dev

The storefront lives in artifacts/sds-snackz-storefront. Source assets are in artifacts/sds-snackz-storefront/public/assets.
